H2 · Private release decisions

Compare adaptive width with and without the gate. Reusing an estimate adds no release cost, but each new private probe spends budget. Staleness remains part of the accuracy measurement.

Gate and width selection

The probe is Gaussian-noised before drift detection or Zipf fitting. The publication decision, width, and fitted exponent are postprocessing of that probe. Its cost is charged even when a release is withheld.

Evaluation boundary

This dashboard exposes exact ground truth, accuracy metrics, and all seven methods for research. It is not a private publication endpoint. Secure aggregation is simulated in one process.
